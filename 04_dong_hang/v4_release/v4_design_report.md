# Generalized V4 release experiment

The full page context is the primary comparison. The 10-, 5- and 15-ID passes are explicit sensitivity experiments. A context cannot be larger than its original source pool. Both methods use the same S4 lines and released T1 strings at each size. Anchorless midpoints are priors only. Cross-page S4 units are submitted whole: denominators count the actual request, not the sum of cropped page lengths.

**Decoder.** `experiment.py` projects the raw response through the existing strict Stage04 resolver. `engine.py` ranks source-linked alternatives from the same Han window, scoped to the primary VI pool. Corroboration means agreement between *distinct payloads*, not independent reviewers. Safe aggregation is inherited from `aggregate_candidates`: complete single-ID fragment chains only, no skipped non-whitespace text. Existing legitimate N–M alignments survive. A coordinated split must uniquely tile both the Han interval and the complete ordered VI parts. Gap recovery and expansion/reassignment cannot displace existing meaningful text. A competing full mapping triggers abstention. Repeated text at different offsets retains separate identities. Weights are conservative heuristic priorities, not calibrated probabilities. No page/ID-specific edits enter this decoder.

**Limitations.** Frozen T1 spelling is used on the wire. V4's reversible normalization supplies auxiliary numeric features; shared digits and literal Latin names are weak evidence across scripts, not a Han name or numeral translation model. Cuts are limited to source-projected alternatives from the existing segmentation/API responses; unsupported linguistic cuts require reviewers. Reassignment is constrained to a corroborated alternative that retains previously assigned VI material. Fresh scores validate neither equivalence nor the weights. Full-context V4 abstained from every proposed change in this run.

## Data and provenance schema

- `requests.jsonl`: endpoint, exact payload, payload key, raw response, attempt, HTTP/application status, latency. Cache keys include endpoint and full payload. Same-ID/key checkpoints resume without another network request; the request log counts actual attempts, not reprocessing passes.
- `results.json`: window, Cap, page list, ordered VI IDs, submitted half-open global Han spans, context size, status, immutable `baseline`, and new `v4` groups. Group identity is `(Cap,Han_Start,Han_End,VI_Char_Spans)`, not the text alone. `Han_Text` and `Vietnamese_Text` are source projections; `VI_Char_Spans` are half-open offsets within original VI IDs. `Validation_Status` distinguishes mapped/partial/ambiguous/untraceable/unpaired; `Alignment_Type`, `API_Score`, `Label_Target`, `Review_Status` are separate. `Original_API_Rows`, `Request_Key`, `VI_Source_Rows`, and `Source_Rows` link back to exact evidence. An unpaired row may have null Han offsets.
- `provenance`: one decision per alternative; `operation`, `before`, `after`, `distinct_requests`, `rank`, `intra_s4`, and `disposition`. Unchanged rows and rejected alternatives remain inspectable. A rank is not confidence in semantic truth.
- `comparison.xlsx`: window/context/method denominators, overlap and order-conflict counts, score distributions, candidate-reference agreement and correction decisions. No fresh reference spans or human labels exist. Missing metrics are unavailable, never zero accuracy.
- `stage04/<cap>/V4/`: numeric window prefixes, unique `id_zh`, `text_zh`, `han_page_start/end`, `global_raw_start/end`. Nonconflicting projected V4 groups supply cuts; unresolved source falls back to S4. These CSVs are Han inputs, not Gold pairs. `source_export` reconstructs the complete input and runs the actual reader.
- `gold_review_packet.xlsx`: distribute this workbook alone. Judge the complete pair, including names, amounts, units, omissions and additions. Use TRUE/FALSE/UNKNOWN and notes. `semantic_review.xlsx` holds the separate private linkage and unresolved list. Proposed labels and model opinions cannot set a human target.

## Run

From the repository root: `python -B 04_dong_hang/v4_release/cli.py all handoff-001`. Use the same run ID to resume, a new ID for a distinct release. `publish` rebuilds reports/CSVs offline from the saved experiment. `consume handoff-001 Cap_02 9 10` checks one window. Existing `SINONOM_TOKEN` is required for the live stages. The package and prior run directories are not output destinations.
